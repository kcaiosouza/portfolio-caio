# Design Spec: Counter-Strike 1.6 (Web / Iframe Integration)

**Date:** 2026-10-02  
**Status:** Approved  
**Author:** Antigravity & Caio Souza  

## 1. Overview & Objectives

Implement Counter-Strike 1.6 playable inside the Caio XP portfolio by embedding `https://play-cs.com/pt/servers` within a dedicated, full-window frame with appropriate sandbox and permission configurations.

### Key Constraints & Decisions:
1. **Window Sizing & Layout**:
   - Opens already maximized (`isMaximized: true`), occupying the entire desktop area above the 36px Windows XP taskbar (`calc(100vh - 36px)`).
   - WindowFrame titlebar remains visible at the top: blue gradient titlebar, title "Counter-Strike 1.6", icon, minimize, restore/maximize, and close buttons.
   - The game iframe occupies 100% of the window body below the titlebar (no extra address bar or surrounding padding).
2. **Iframe Security & Capabilities**:
   - URL: `https://play-cs.com/pt/servers`
   - `sandbox="allow-scripts allow-same-origin allow-pointer-lock allow-popups allow-forms"`
     - **NO `allow-top-navigation`**: prevents the iframe from breaking out of or redirecting the portfolio.
   - `allow="autoplay; fullscreen; pointer-lock; gamepad; cross-origin-isolated"`
     - Enables sound, pointer lock (essential for FPS mouse camera movement), and game controls.
3. **Application Icon**:
   - Source: `counter_strike_1_6_hq_icon_by_fabritor100_dbpjpqu-fullview.jpg`
   - Resized and converted to WebP via `ffmpeg`: `public/assets/cs16-icon.webp` (96x96 / 128x128).
4. **Placement & Entry Points**:
   - **NOT on Desktop**: per user instruction, no icon on the desktop.
   - **Inside Hobbies Folder (`hobbies`)**: added to `HOBBIES_ITEMS` as `Counter-Strike 1.6.exe`. Double-clicking opens `cs-window`.
   - **CMD Terminal**: typing `cstrike` (or `cs`, `cs16`) opens `cs-window`.
   - **Taskbar & WindowFrame**: displays the WebP CS 1.6 icon.
5. **Git Constraint**:
   - **DO NOT PUSH TO REMOTE REPOSITORY**. Local commits only.

## 3. Detailed Specifications

### 3.1 Icon Conversion (`ffmpeg`)
- Command:
  ```bash
  ffmpeg -i counter_strike_1_6_hq_icon_by_fabritor100_dbpjpqu-fullview.jpg -vf "scale=128:128" -c:v libwebp -quality 90 -y public/assets/cs16-icon.webp
  ```

### 3.2 `CsApp.tsx`
- Component definition:
  ```tsx
  export const CsApp: React.FC<{ isOpen?: boolean; onClose?: () => void }> = ({ isOpen, onClose }) => {
    return (
      <WindowFrame
        id="cs-window"
        title="Counter-Strike 1.6"
        icon="cs"
        isOpen={isOpen}
        onClose={onClose}
        initialPosition={{ x: 30, y: 15, width: 1024, height: 680 }}
      >
        <div className="w-full h-full bg-black select-none overflow-hidden flex flex-col">
          <iframe
            src="https://play-cs.com/pt/servers"
            title="Counter-Strike 1.6"
            className="w-full h-full border-none"
            sandbox="allow-scripts allow-same-origin allow-pointer-lock allow-popups allow-forms"
            allow="autoplay; fullscreen; pointer-lock; gamepad; cross-origin-isolated"
          />
        </div>
      </WindowFrame>
    );
  };
  ```

### 3.3 `WindowContext.tsx`
- In `DEFAULT_WINDOWS`:
  ```typescript
  {
    id: 'cs-window',
    title: 'Counter-Strike 1.6',
    icon: 'cs',
    isOpen: false,
    isMinimized: false,
    isMaximized: true,
    zIndex: 10,
    position: { x: 30, y: 15, width: 1024, height: 680 },
    defaultPosition: { x: 30, y: 15, width: 1024, height: 680 }
  }
  ```

### 3.4 `ExplorerFolderApp.tsx` & `data.ts`
- In `HOBBIES_ITEMS`:
  ```typescript
  {
    id: 'cstrike',
    title: 'Counter-Strike 1.6.exe',
    type: 'game',
    content: 'https://play-cs.com/pt/servers',
    description: 'FPS tático clássico jogável via navegador',
    windowId: 'cs-window'
  }
  ```
- In `ExplorerFolderApp.tsx`:
  - When `hobby.type === 'game'` or `hobby.id === 'cstrike'`, render `<img src="/assets/cs16-icon.webp" className="w-10 h-10 object-contain drop-shadow-md" />`.
  - Double clicking invokes `wm.openWindow(hobby.windowId || 'cs-window')`.

### 3.5 `cmdEngine.ts`
- Case:
  ```typescript
  case 'cstrike':
  case 'cs':
  case 'cs16':
    ctx.openWindow('cs-window');
    return { output: ['Iniciando Counter-Strike 1.6...'] };
  ```
